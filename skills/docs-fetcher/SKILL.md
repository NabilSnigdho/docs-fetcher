---
name: docs-fetcher
description: Fetch a documentation web page as clean Markdown with the docs-fetcher CLI. Use when you need to read the contents of a docs URL (JS-rendered pages included) and save it locally.
---

Run `docs-fetcher <url> <dir>`. It renders the page, converts it to Markdown, writes `<dir>/<host-and-path-slug>.md`, and prints the file path. Read that file afterwards.

Update this skill with `docs-fetcher install-skill`.
